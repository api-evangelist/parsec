# Parsec

> Parsec is a high-performance, low-latency remote desktop and interactive video streaming product (a Unity company) used to access graphics-intensive, latency-sensitive applications from anywhere. Parsec for Teams adds organization-wide administration, and the Parsec for Teams API exposes that admin surface — members, groups, machines, guest access, app rules, relays, and the audit log — to applications.

## APIs
- [Parsec for Teams](https://parsec.app/teams): Admin API for managing team members, groups, machines, guest access, app rules, relays, and audit logs. Base URL https://api.parsec.app, HTTP Bearer API-key auth.
